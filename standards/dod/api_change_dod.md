## Overview

This Definition of Done applies to all work items classified as **API Change** — modifications to REST endpoints, GraphQL schemas, Kafka event schemas, or any public API contract exposed by the Commerce Platform team.

**Key Characteristics of API Change Work:**
- Modifies request/response schemas, endpoint paths, HTTP methods, or event structures
- Requires OpenAPI specification updates and API diff generation
- May affect external consumers (other teams, third-party integrations, mobile apps)
- Must maintain backward compatibility unless version is bumped
- Includes contract testing and integration testing requirements
