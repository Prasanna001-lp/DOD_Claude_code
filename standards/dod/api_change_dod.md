## Code Quality

**[ ] [L1-UNIVERSAL] [ENG-4.1]** PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.  
**Verification:** GitHub PR shows 2+ approvals with at least 1 from senior/lead engineer.  
**Exception:** No exceptions.

**[ ] [L2-WORKTYPE] [ENG-4.1-SEC]** Security-critical PRs have approval from Security Champion in addition to standard 2 approvals.  
**Verification:** GitHub PR shows @security-champion approval for changes touching authentication, authorization, or payment flows.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [ENG-4.2-SIGN]** All commits in PR are signed with GPG or SSH key registered in GitHub.  
**Verification:** GitHub shows "Verified" badge on all commits in PR.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [ENG-4.2-CONV]** All commit messages follow Conventional Commits format: type(scope): description.  
**Verification:** commitlint check passes in GitHub Actions workflow.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [ENG-4.2-MERGE]** PR merged using squash merge (verified by GitHub branch protection).  
**Verification:** GitHub branch protection enforces squash merge only on main branch.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [ENG-4.3-COMPLEXITY]** SonarQube quality gate passes with cyclomatic complexity ≤ 10 per method.  
**Verification:** SonarQube CI check shows Quality Gate PASSED with no methods exceeding complexity 10.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [ENG-4.3-LOC]** No method exceeds 50 lines of code (enforced by SonarQube).  
**Verification:** SonarQube CI check shows no methods > 50 LOC.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [ENG-4.3-DEAD]** No dead code, unreachable code, or commented-out code present (SonarQube detects).  
**Verification:** SonarQube shows 0 dead code issues in changed modules.  
**Exception:** No exceptions.

## Test Coverage & Quality

**[ ] [L1-UNIVERSAL] [QA-2.1-LINE]** JaCoCo reports ≥80% line coverage on all changed modules in CI.  
**Verification:** JaCoCo CI check passes with 80%+ line coverage report in GitHub Actions.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [QA-2.1-BRANCH]** JaCoCo reports ≥75% branch coverage on all changed modules in CI.  
**Verification:** JaCoCo CI check passes with 75%+ branch coverage report in GitHub Actions.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [QA-2.1-REGRESS]** CI build passes coverage regression check (no covered code lost coverage).  
**Verification:** JaCoCo diff coverage check shows 0 regression in GitHub Actions build logs.  
**Exception:** No exceptions.

**[ ] [L2-WORKTYPE] [QA-2.2-API-UNIT]** Unit tests present for API endpoint logic (JUnit 5).  
**Verification:** CI shows JUnit 5 tests executing for controller/service layer classes modified in PR.  
**Exception:** No exceptions.

**[ ] [L2-WORKTYPE] [QA-2.2-API-INT]** Integration tests present for API endpoint (Spring Boot Test with MockMvc).  
**Verification:** CI shows @WebMvcTest or @SpringBootTest annotated tests executing for API endpoint.  
**Exception:** No exceptions.

**[ ] [L2-WORKTYPE] [From INC-002]** API contract test includes test cases for all nullable fields documented in OpenAPI spec.  
**Verification:** Contract tests in CI cover all nullable fields from api/openapi.yaml (verified in PR review).  
**Exception:** No exceptions.

**Exception:** Tech Lead can grant exemption for batch/admin endpoints not user-facing.

## Security

**[ ] [L1-UNIVERSAL] [SEC-3.1-SNYK]** Snyk scan shows 0 Critical or High severity findings in CI.  
**Verification:** Snyk GitHub Actions check shows PASSED with 0 Critical/High findings.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [SEC-3.1-MEDIUM]** Medium severity Snyk findings acknowledged with tracked Jira ticket (ticket linked in PR).  
**Verification:** PR description contains Jira ticket links for all Medium severity findings from Snyk scan.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [SEC-3.2-GITLEAKS]** Gitleaks scan passes with 0 secrets detected in CI.  
**Verification:** Gitleaks GitHub Actions check shows PASSED with no secrets found.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [SEC-3.3-DEPS]** All dependencies in pom.xml/package.json exist in approved dependency registry.  
**Verification:** Dependency check script passes in CI confirming all dependencies are pre-approved.  
**Exception:** EM can grant exemption with CISO sign-off for new dependencies.

**[ ] [L1-UNIVERSAL] [SEC-3.3-CVE]** No dependencies with Critical CVEs older than 5 business days present.  
**Verification:** Snyk CI check shows 0 Critical CVEs with disclosure date > 5 business days ago.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [SEC-3.3-AUDIT]** npm audit (React) or mvn dependency:check (Java) shows 0 Critical findings in CI.  
**Verification:** npm audit or mvn dependency:check CI job shows 0 Critical vulnerabilities in build output.  
**Exception:** No exceptions.

**[ ] [L1-UNIVERSAL] [SEC-4.2-STORAGE]** All secrets stored in AWS Secrets Manager or GitHub Actions secrets (verified in code review).  
**Verification:** Code review confirms no hardcoded secrets; all secrets loaded from AWS Secrets Manager or GitHub Actions.  
**Exception:** No exceptions.

## Documentation

**[ ] [L2-WORKTYPE] [ENG-6.1-API]** OpenAPI specification file (api/openapi.yaml) updated to reflect API changes.  
**Verification:** git diff shows api/openapi.yaml modified with endpoint/schema changes matching PR code.  
**Exception:** EM can grant exemption if API change is internal-only (not exposed to external consumers).

**[ ] [L2-WORKTYPE] [ENG-6.1-API]** CHANGELOG.md updated with entry under [Unreleased] describing API change.  
**Verification:** git diff shows CHANGELOG.md modified with new entry under [Unreleased] section.  
**Exception:** No exceptions.

**[ ] [L2-WORKTYPE] [ENG-6.1-API]** API diff generated and attached to PR (using openapi-diff or equivalent).  
**Verification:** PR description or comment contains openapi-diff output showing breaking/non-breaking changes.  
**Exception:** No exceptions.

**[ ] [L3-TEAM] [TEAM-COMMERCE-PLATFORM]** Kafka event schema updated in schemas/ directory if API change publishes events.  
**Verification:** git diff shows schemas/*.avsc or schemas/*.json modified for event schema changes, or PR confirms no event changes.  
**Exception:** No exceptions.

## CI / Deployment Gate

**[ ] [L1-UNIVERSAL] [UNIVERSAL-CI]** All GitHub Actions checks pass (lint, build, test, security scan).  
**Verification:** GitHub PR shows all required checks green before merge is enabled.  
**Exception:** No exceptions.

**[ ] [L2-WORKTYPE] [QA-2.4-PERF-K6]** k6 load test included in CI for endpoints handling > 1000 RPS.  
**Verification:** CI workflow includes k6 test execution step for high-traffic endpoints (verified in .github/workflows/).  
**Exception:** Tech Lead can grant exemption if endpoint traffic < 1000 RPS (documented in PR).

**Verification:** CI shows Flyway/Liquibase migration applied cleanly in test environment logs.  
**Exception:** No exceptions if schema changes present.
