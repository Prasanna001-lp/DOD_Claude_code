## Code Quality

**[ ] [L1] [ENG-4.1] PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.**  
**Verification:** GitHub PR review status shows 2+ approvals with at least 1 from senior engineer role.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.1-SEC] Security-critical PRs have approval from designated Security Champion in addition to standard approvals.**  
**Verification:** GitHub PR review comments include approval from engineer tagged as Security Champion if PR modifies security groups, IAM policies, encryption configs, or network ACLs.  
**Exception:** No exceptions for security-critical infrastructure changes.

**[ ] [L1] [ENG-4.2] All commits in PR are signed with GPG or SSH key registered in GitHub.**  
**Verification:** GitHub commit history shows "Verified" badge on all commits in PR.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.2] All commit messages follow Conventional Commits format (type(scope): description).**  
**Verification:** GitHub Actions workflow "Conventional Commits Check" passes; all commit messages match pattern: `(feat|fix|docs|style|refactor|test|chore|infra)(scope)?: description`  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.2] PR is configured for squash merge (merge commits prohibited).**  
**Verification:** GitHub PR merge button shows only "Squash and merge" option enabled.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.3] SonarQube quality gate passes with cyclomatic complexity ≤ 10 per method.**  
**Verification:** SonarQube GitHub Actions check passes; SonarQube dashboard shows 0 methods exceeding complexity threshold 10.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.3] SonarQube reports zero methods exceeding 50 lines of code.**  
**Verification:** SonarQube dashboard Code Smells section shows 0 violations for "Methods should not have too many lines".  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.3] SonarQube reports zero dead code (unreachable or commented-out code).**  
**Verification:** SonarQube dashboard shows 0 issues tagged "unused" or "commented-out".  
**Exception:** No exceptions.

## Security

**[ ] [L1] [SEC-3.1] Snyk security scan reports 0 Critical severity findings in CI.**  
**Verification:** GitHub Actions "Snyk Security Scan" workflow passes; Snyk report shows 0 Critical severity vulnerabilities.  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.1] Snyk security scan reports 0 High severity findings in CI.**  
**Verification:** Snyk report shows 0 High severity vulnerabilities.  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.1] All Medium severity Snyk findings acknowledged with tracked Jira ticket reference in PR description.**  
**Verification:** If Snyk reports Medium findings, PR description contains Jira ticket IDs (format: JIRA-NNNN) for each finding.  
**Exception:** No exceptions. All Medium findings must be acknowledged.

**[ ] [L1] [SEC-3.2, SEC-4.2] Gitleaks scan passes in CI with 0 secrets detected.**  
**Verification:** GitHub Actions "Gitleaks Scan" workflow passes; Gitleaks report shows 0 secrets, API keys, tokens, or passwords detected in commit history.  
**Exception:** No exceptions.

**[ ] [L1] [SEC-4.2] All application secrets stored in AWS Secrets Manager or GitHub Actions secrets (documented in PR description).**  
**Verification:** PR description contains section "Secrets Management" listing all secrets referenced in IaC and confirming storage location (AWS Secrets Manager ARN or GitHub Actions secret name).  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.3] All new dependencies present in approved dependency registry (referenced in PR description).**  
**Verification:** PR description lists all new Terraform modules, providers, or third-party libraries with approval status (approved by Security Champion or documented in `dependency_approvals.yaml`).  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.3] Dependency vulnerability scan (mvn dependency:check) reports 0 Critical CVE findings in CI.**  
**Verification:** GitHub Actions "Dependency Check" workflow passes for Java-based IaC tooling or Lambda functions; report shows 0 Critical CVEs.  
**Exception:** No exceptions.

**[ ] [L2] [SEC-4.1] Terraform plan output attached to PR showing no unintended resource deletions.**  
**Verification:** PR description or comment contains `terraform plan` output; plan shows 0 resources marked for deletion unless explicitly intended and documented in PR body under "Resource Deletions" section.  
**Exception:** No exceptions. All deletions must be intentional and documented.
