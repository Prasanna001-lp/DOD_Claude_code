## Purpose
This Definition of Done ensures all infrastructure-as-code changes meet Acme Engineering's quality, security, and operational standards before deployment to production.

Infrastructure changes include: Terraform modules, AWS resource provisioning, network configuration, IAM policies, CI/CD pipeline updates, monitoring configuration, and disaster recovery procedures.

## Code Quality

### [ ] [L1] [ENG-4.1] PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.
**Verification:** GitHub PR approval count shows ≥ 2 approvals. At least 1 approval from an engineer with "Senior Engineer" or "Tech Lead" role in GitHub team settings.  
**Exception:** No exceptions.

### [ ] [L2] [ENG-4.1-SEC] PR touching security-critical paths has approval from Security Champion.
**Verification:** If PR modifies files in auth/, security/, crypto/, or IAM policy directories, GitHub PR shows approval from user with "Security Champion" role.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.2-SIGN] All commits are signed with GPG or SSH key registered in GitHub.
**Verification:** GitHub shows "Verified" badge on all commits in the PR. GitHub Actions commit signature verification check passes.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.2-CONV] All commit messages follow Conventional Commits format: type(scope): description.
**Verification:** GitHub Actions runs commitlint check. CI passes with zero commit message violations.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.2-MERGE] PR merged using squash merge strategy (no merge commits on main).
**Verification:** GitHub PR settings enforce "Squash and merge" only. Main branch protection rule blocks merge commits.  
**Exception:** No exceptions.

### [ ] [L2] [SEC-4.1-TERRAFORM] terraform plan output shows no unintended resource deletions.
**Verification:** terraform plan output attached to PR comment. Plan shows only expected resource changes. No resource deletions unless explicitly documented in PR description.  
**Exception:** EM can grant one-sprint exemption with written justification.

### [ ] [L2] [SEC-4.1-TERRAFORM] Platform Engineering team approval recorded on PR.
**Verification:** GitHub PR shows approval from user with "Platform Engineering" team membership.  
**Exception:** EM can grant one-sprint exemption with written justification.
