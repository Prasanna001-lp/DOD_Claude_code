## Overview

This Definition of Done checklist applies to all **infrastructure** work items in the Commerce Platform team. It synthesises requirements from:

- Engineering Handbook (ENG)
- QA Policy (QA)
- Security Policy (SEC)
- Escaped Defect Log (production incidents)
- Commerce Platform team standards (TEAM)

Every criterion is **verifiable** (binary pass/fail), **traceable** to a source policy, and **tool-specific** to the team's tech stack.

## Code Quality

### [ ] [L1-UNIVERSAL] [ENG-4.1] PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.
**Verification:** GitHub PR shows 2+ approvals with at least 1 from senior/lead engineer.  
**Exception:** No exceptions.

### [ ] [L2-WORKTYPE] [ENG-4.1-SEC] Security-critical infrastructure changes have approval from Security Champion in addition to standard 2 approvals.
**Verification:** GitHub PR shows @security-champion approval in addition to 2 standard approvals.  
**Exception:** No exceptions.

### [ ] [L1-UNIVERSAL] [ENG-4.2-SIGN] All commits in PR are signed with GPG or SSH key registered in GitHub.
**Verification:** GitHub shows "Verified" badge on all commits in the PR.  
**Exception:** No exceptions.

### [ ] [L1-UNIVERSAL] [ENG-4.2-CONV] All commit messages follow Conventional Commits format: type(scope): description.
**Verification:** commitlint check passes in GitHub Actions workflow.  
**Exception:** No exceptions.

### [ ] [L1-UNIVERSAL] [ENG-4.2-MERGE] PR merged using squash merge (verified by GitHub branch protection).
**Verification:** GitHub branch protection enforces squash merge only on main branch.  
**Exception:** No exceptions.

### [ ] [L2-WORKTYPE] [ENG-6.2-ADR] ADR created in docs/adr/ documenting architectural change.
**Verification:** git diff shows new file in docs/adr/ with ADR number and decision context.  
**Exception:** No exceptions.

### [ ] [L2-WORKTYPE] [ENG-6.2-ADR] Architecture Guild review approval recorded in PR (reviewer tagged @arch-guild).
**Verification:** GitHub PR shows approval from @arch-guild member.  
**Exception:** No exceptions.

### [ ] [L3-TEAM] [TEAM-INFRA-01] Terraform configuration follows Commerce Platform naming conventions (env-region-service format).
**Verification:** Code review confirms resource names follow {env}-{region}-{service} pattern.  
**Exception:** Tech Lead can grant exemption for vendor-specific naming requirements.
