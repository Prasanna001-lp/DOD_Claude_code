## Code Quality

**[ ] [L1] [ENG-4.1]** PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.  
**Verification:** GitHub PR approval count shows 2+ approvals, with at least 1 from senior engineer role.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.2]** All commits in PR are signed with GPG or SSH key registered in GitHub.  
**Verification:** GitHub shows "Verified" badge on all commits in PR.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.2]** All commit messages follow Conventional Commits format: type(scope): description.  
**Verification:** GitHub Actions commitlint check passes in CI pipeline.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.2]** PR merged using squash merge (no merge commits on main).  
**Verification:** GitHub PR settings enforce squash merge; git log shows single commit per PR on main branch.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.3]** SonarQube quality gate passes with cyclomatic complexity ≤ 10 per method.  
**Verification:** SonarQube dashboard shows quality gate PASSED status with 0 complexity violations.  
**Exception:** No exceptions.

**[ ] [L1] [ENG-4.3]** No method exceeds 50 lines of code (SonarQube check).  
**Verification:** SonarQube reports 0 violations for rule "Methods should not have too many lines".  
**Exception:** No exceptions.

**[ ] [L2] [ENG-4.3]** No dead code (unreachable, commented-out) present in changed files.  
**Verification:** SonarQube reports 0 violations for "Dead Code" category on changed files.  
**Exception:** No exceptions.

**[ ] [L2] [ENG-6.2]** No new technical debt introduced (SonarQube technical debt ratio ≤ baseline).  
**Verification:** SonarQube shows technical debt ratio has not increased compared to main branch baseline.  
**Exception:** EM approval required if technical debt increases; must have offsetting debt reduction plan documented in Jira.

## Test Coverage & Quality

**[ ] [L1] [QA-2.1]** JaCoCo reports 80%+ line coverage on all changed modules in CI.  
**Verification:** GitHub Actions build log shows JaCoCo line coverage ≥ 80% for each changed module.  
**Exception:** No exceptions.

**[ ] [L1] [QA-2.1]** JaCoCo reports 75%+ branch coverage on all changed modules in CI.  
**Verification:** GitHub Actions build log shows JaCoCo branch coverage ≥ 75% for each changed module.  
**Exception:** No exceptions.

**[ ] [L1] [QA-2.1]** No existing covered code has lost coverage (CI fails on coverage regression).  
**Verification:** JaCoCo coverage comparison report shows 0 lines/branches lost coverage compared to main branch.  
**Exception:** No exceptions.

**[ ] [L2] [QA-2.2-DEBT]** Unit tests present for refactored logic (JUnit 5).  
**Verification:** Test classes exist in src/test/java for all refactored classes; tests execute in CI.  
**Exception:** No exceptions.

**[ ] [L2] [QA-2.2-DEBT]** Integration tests present for refactored components (JUnit 5).  
**Verification:** Integration test classes exist for refactored service integrations; tests execute in CI with @SpringBootTest annotation.  
**Exception:** No exceptions.

**[ ] [L3] [TEAM-STANDARD]** Mockito used for all external dependencies in unit tests (no real Kafka/PostgreSQL connections).  
**Verification:** Test code uses @Mock or @MockBean annotations; no real database or message broker connections in unit tests.  
**Exception:** Tech Lead approval if embedded test infrastructure required; must document rationale in PR.

## Security

**[ ] [L1] [SEC-3.1]** Snyk scan shows 0 Critical or High severity findings.  
**Verification:** GitHub Actions Snyk check passes; Snyk dashboard shows 0 Critical/High vulnerabilities.  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.1]** Snyk Medium severity findings have tracked Jira tickets before merge.  
**Verification:** All Snyk Medium findings have corresponding Jira ticket IDs documented in PR description or Snyk dashboard.  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.2 / SEC-4.2]** Gitleaks scan passes with 0 secrets detected in CI.  
**Verification:** GitHub Actions Gitleaks check passes; workflow log shows "No leaks detected".  
**Exception:** No exceptions.

**[ ] [L1] [SEC-3.3]** mvn dependency:check (Java) or npm audit (Node.js) reports 0 Critical CVE findings in CI.  
**Verification:** GitHub Actions build log shows "mvn dependency:check" exit code 0 with no Critical CVEs listed.  
**Exception:** No exceptions.

**[ ] [L2] [SEC-3.3]** All third-party dependencies listed in approved dependency registry.  
**Verification:** All dependencies in pom.xml or package.json appear in Confluence "Approved Dependencies" page.  
**Exception:** Tech Lead approval if new dependency required; must document justification and security review in PR.

## Architecture & Documentation

**[ ] [L2] [ENG-6.2]** Architecture Decision Record (ADR) created in docs/adr/ for architecture/data model/contract changes.  
**Verification:** New ADR file exists in docs/adr/ directory following ADR template; file committed in PR.  
**Exception:** No exceptions if refactoring changes architecture, data model, or service contracts.

**[ ] [L2] [ENG-6.2]** Architecture Guild review completed and approval documented in PR.  
**Verification:** PR has approval from Architecture Guild member (tagged @architecture-guild); review notes in PR comments.  
**Exception:** No exceptions if ADR was required (ARCH-01).

**[ ] [L3] [TEAM-STANDARD]** README.md updated if component behavior, configuration, or dependencies changed.  
**Verification:** README.md file modified in git diff if refactoring affects component usage, setup, or configuration.  
**Exception:** Tech Lead approval if no README update required; must document rationale in PR.

**[ ] [L3] [TEAM-STANDARD]** Javadoc updated for all public API changes (Java) or JSDoc for React components.  
**Verification:** Modified .java files with public methods include /** Javadoc */ comments; React .tsx files with exported components include JSDoc.  
**Exception:** No exceptions for public APIs.

**Exception:** No exceptions.

**[ ] [L3] [TEAM-STANDARD]** ESLint passes with 0 errors for React/TypeScript code.  
**Verification:** GitHub Actions ESLint workflow shows exit code 0; no errors in workflow log.  
**Exception:** No exceptions.

**[ ] [L3] [TEAM-STANDARD]** Spotless Java formatter applied (mvn spotless:check passes).  
**Verification:** GitHub Actions build log shows "mvn spotless:check" passed; no formatting violations.  
**Exception:** No exceptions.
