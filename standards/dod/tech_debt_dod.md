## Code Quality

### [ ] [L1] [ENG-4.1] PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.
**Verification:** GitHub PR approval count shows ≥ 2 approvals. At least 1 approval from an engineer with "Senior Engineer" or "Tech Lead" role in GitHub team settings.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.2-SIGN] All commits are signed with GPG or SSH key registered in GitHub.
**Verification:** GitHub shows "Verified" badge on all commits in the PR. CI enforces commit signature verification.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.2-CONV] All commit messages follow Conventional Commits format: type(scope): description.
**Verification:** GitHub Actions runs commitlint check. CI passes with zero commit message violations.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.2-MERGE] PR merged using squash merge strategy (no merge commits on main).
**Verification:** GitHub PR settings enforce "Squash and merge" only. Main branch protection rule blocks merge commits.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.3-COMPLEXITY] SonarQube quality gate passes: cyclomatic complexity ≤ 10 per method.
**Verification:** SonarQube CI check passes. Quality gate shows zero methods with complexity > 10.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.3-LOC] No method exceeds 50 lines of code (SonarQube enforces).
**Verification:** SonarQube CI check passes. Quality gate shows zero methods with LOC > 50.  
**Exception:** No exceptions.

### [ ] [L1] [ENG-4.3-DEAD] SonarQube reports zero dead code issues (unreachable, commented-out code removed).
**Verification:** SonarQube CI check passes. Quality gate shows zero dead code issues.  
**Exception:** No exceptions.

### [ ] [L3] [TEAM-TECH-STACK] No new technical debt introduced: SonarQube technical debt ratio has not increased.
**Verification:** SonarQube CI check compares technical debt ratio against main branch. Build fails if ratio increases.  
**Exception:** Tech Lead approval required if ratio increases with documented justification in PR description.
