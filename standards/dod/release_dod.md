## Overview

This Definition of Done applies to all **Release** work items for the Commerce Platform team. Every criterion must be verified and checked before a release is marked as complete.

**Layer Legend:**
- **[L1-UNIVERSAL]** — Applies to ALL work items; cannot be overridden (EM + CISO sign-off required to modify)
- **[L2-WORKTYPE]** — Applies to all Release items; EM can grant one-sprint exemption with written justification
- **[L3-TEAM]** — Team-specific criteria based on Commerce Platform tech stack and practices
- **[L4-STORY]** — Story-specific additions defined during release grooming (optional)
