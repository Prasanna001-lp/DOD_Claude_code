## Overview

This Definition of Done applies to **Release** work items. A release represents the deployment of code changes to production and requires comprehensive validation across all quality dimensions.

**Key Characteristics:**
- Includes ALL merged changes since last release
- Requires full regression testing in staging and pre-production
- Requires post-deployment smoke testing in production
- Requires explicit Engineering Manager sign-off
- Must include rollback plan tested in non-production environment
- Requires updated release notes and operational runbooks
