## Code Quality

### CODE-01 [L1] [ENG-4.1]
**Criterion:** PR has minimum 2 approvals from engineers other than the author, including 1 from a senior engineer or tech lead.

**Verification:** GitHub PR page shows 2+ approvals with at least 1 from senior engineer role.

**Exception:** No exceptions.

**Source:** engineering_handbook.md § 4.1 Pull Request Requirements

---

### CODE-02 [L1] [ENG-4.2-SIGN]
**Criterion:** All commits in PR are signed with GPG or SSH key registered in GitHub.

**Verification:** GitHub PR shows "Verified" badge on all commits.

**Exception:** No exceptions.

**Source:** engineering_handbook.md § 4.2 Commit Standards

---

### CODE-03 [L1] [ENG-4.2-CONV]
**Criterion:** All commit messages follow Conventional Commits format: type(scope): description.

**Verification:** GitHub Actions commitlint check passes.

**Exception:** No exceptions.

**Source:** engineering_handbook.md § 4.2 Commit Standards

---

### CODE-04 [L1] [ENG-4.2-MERGE]
**Criterion:** PR merge strategy set to "Squash and merge". Merge commits are not used on main branch.

**Verification:** GitHub PR settings show "Squash and merge" selected.

**Exception:** No exceptions.

**Source:** engineering_handbook.md § 4.2 Commit Standards

## Security

### SEC-01 [L1] [SEC-3.1-SNYK]
**Criterion:** Snyk scan shows 0 Critical or High severity findings. Medium findings acknowledged with tracked Jira ticket.

**Verification:** GitHub Actions Snyk check passes. Medium findings have Jira ticket links in PR description.

**Exception:** No exceptions.

**Source:** security_policy.md § 3.1 Mandatory Scanning

---

### SEC-02 [L1] [SEC-3.2]
**Criterion:** Gitleaks scan in CI pipeline passed with zero secrets detected. All secrets stored in AWS Secrets Manager or GitHub Actions secrets.

**Verification:** GitHub Actions Gitleaks check passes. PR description confirms secret storage location when secrets used.

**Exception:** No exceptions.

**Source:** security_policy.md § 3.2 Secrets Scanning, § 4.2 Credentials and Secrets (consolidated from OVERLAP-001)

---

### SEC-03 [L1] [SEC-3.3-DEPS]
**Criterion:** Maven dependency:check (for Java) or npm audit (for Node.js) ran in CI with zero Critical CVE findings.

**Verification:** GitHub Actions Maven/NPM check passes showing 0 Critical CVEs.

**Exception:** No exceptions.

**Source:** security_policy.md § 3.3 Dependency Management
